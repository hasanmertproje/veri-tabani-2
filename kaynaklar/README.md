# Kaynaklar

Bu bölüm, **Veri Tabanı 2** dersi için yararlanılan yardımcı kaynakları düzenli biçimde tutmak amacıyla oluşturulmuştur.

## Kaynak Türleri

Buraya zamanla aşağıdaki türlerde kaynaklar eklenecektir:

- Microsoft Access dokümantasyonu
- SQL konu anlatımları
- Veritabanı tasarım örnekleri
- Normalizasyon örnekleri
- Primary Key / Foreign Key anlatımları
- Sorgu örnekleri
- Ders sırasında paylaşılan dosya ve bağlantılar
- Sınav öncesi tekrar kaynakları

## Kaynak Ekleme Formatı

Yeni kaynaklar mümkünse şu biçimde eklenecektir:

```markdown
### Kaynak Adı

- Bağlantı: https://...
- Konu: Primary Key / Access / SQL vb.
- Neden faydalı: Kısa açıklama
- Eklenme tarihi: YYYY-MM-DD
```

## Ders Kaynakları

Henüz özel bir ders kaynağı eklenmedi.

> Öğretim elemanının paylaştığı doküman, ekran görüntüsü, PDF veya bağlantılar geldikçe burada konu bazlı olarak listelenecektir.
